Fluxo de Autenticação

Plataforma Plum

Nota: Este documento detalha como o processo de autenticação e criação de contas se comunica com o Supabase, descrevendo o passo a passo para cada uma das três jornadas do usuário.

1) Criar Organização (Admin)

Este fluxo acontece quando uma nova empresa está aderindo à Plataforma Plum.

Passo Ação do Front-end Função Acionada no Supabase
1. Validação O usuário insere o nome da empresa e o ID de 4 dígitos. supabase.from('organizations').select('id') para garantir que o ID não está em uso.
2. Criação O front-end envia os dados de login e metadados. supabase.auth.signUp() enviando is_admin_setup, org_name, org_share_id e status: ativo.
3. Banco O banco de dados intercepta a criação do usuário automaticamente. Um Database Trigger captura os metadados, cria a nova linha na tabela organizations e cria o perfil atrelado como admin.
4. Notificação O sistema envia um e-mail de boas-vindas. supabase.functions.invoke('send-auth-email') com type: organization_created.

2) Entrar em uma Organização cadastrando a conta (Membro)

Este fluxo acontece quando um funcionário recebeu o ID da empresa e vai criar sua conta.

Passo Ação do Front-end Função Acionada no Supabase
1. Busca O usuário digita o ID da empresa de 4 dígitos. supabase.from('organizations').select('id, name') busca para confirmar que a empresa existe.
2. Cadastro O front-end envia e-mail, senha e o ID da empresa. supabase.auth.signUp() enviando metadados organization_id e status: pendente.
3. Banco O banco de dados intercepta a criação automaticamente. Um Database Trigger cria a linha na tabela profiles com o status pendente (o que bloqueia acesso ao dashboard).
4. Aprovação O front-end avisa o Admin que há uma conta nova. supabase.functions.invoke('send-auth-email') com type: new_request.

3) Entrar em uma Organização pelo login (Usuário Existente)

Este fluxo é para quem já tem a conta criada, independente do status.

Passo Ação do Front-end Função Acionada no Supabase
1. Busca (Opcional) O usuário digita o ID da empresa (se optar pelo painel). supabase.from('organizations').select('id, name')
2. Autenticação O usuário insere e-mail e senha e clica em Entrar. supabase.auth.signInWithPassword() valida as credenciais.
3. Acesso Se a senha estiver correta, um token JWT é gerado e há o redirecionamento. Redirecionamento para /dashboard. O Supabase RLS usa o JWT para filtrar a segurança.
